## Not covered by this run

- **A real phone call.** The webhook checks above send the same messages Vapi sends, but speech recognition, the LLM's conversation and the voice are only exercised by calling the number.
- **The Vapi platform itself**: assistant configuration, phone number routing and call audio.
- **Load beyond a few dozen simultaneous requests**, and behaviour with more than one server process (the duplicate-save guard is an in-process lock).
- **Authentication on the REST API**: there is none, by design for this assessment, so anyone with the URL can read and change records.
